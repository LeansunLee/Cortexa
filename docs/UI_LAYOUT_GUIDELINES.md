# 全站布局设计规范

生效日期：2026-09-08。后续页面开发、改版和验收均遵循此规范；本规范取代早期版本文档中的页面布局约定。

## 应用框架

- 登录后的页面统一使用 `App.vue` 中的侧栏与内容区，内容区顶部设置 44px 页面标签栏，不额外设置全局账号顶栏。
- 侧栏顶部放品牌与工作空间切换，中部为导航并独立滚动，底部依次固定用户与权限、模型用量、系统配置与账号入口，各管理入口按现有权限显示。
- 账号入口显示头像、姓名和展开图标；姓名超长时截断。菜单向上展开，包含个性化设置、修改密码、退出登录；用户与权限入口位于左侧导航的模型用量上方。
- 账号按钮支持 Enter/Space；菜单支持 Tab 导航、Escape 关闭并恢复按钮焦点、点击外部或焦点移出时关闭，切换页面时关闭。
- 应用占满动态视口高度。内容滚动时侧栏底部账号入口保持可见，导航过长时只滚动导航区域。

## 内容与页面操作

- 外边距由 `.page-content` 唯一提供，页面根节点不再叠加整页 padding。
- 页面根容器左对齐，禁止使用 `margin: 0 auto` 将整页（含标题）再次居中；知识库等列表管理页使用内容区全宽。
- 知识库数量和共享范围使用紧凑信息行；不重复设置占据整行卡片的流程说明。
- 桌面内容顶部与底部各 24px，左右各 32px；900px 以下各 20px；640px 以下各 16px。
- 顶部页面标签已明确标识当前页面，业务页面不再重复显示左上角主标题及说明。
- 页面存在顶层操作时继续使用 `PageHeader` 承载操作区，操作按钮左对齐并与正文相隔 24px；没有顶层操作时 `PageHeader` 不占据空间。窄屏允许操作换行。
- 页头新建按钮使用共享类 `btn btn-primary btn-page-action`：高度 40px、水平内边距 20px、字号 14px / 行高 20px、字重 600；加号使用 16px 图标，与文字间距 6px，圆角使用全局 `--radius-sm`。智能体与空间知识库页遵循此规则。
- 对话等多栏工作区不重复显示页面主标题与说明；内部保留历史对话、当前会话名称等局部标题。对话页的「新建对话」按钮位于左侧「历史对话」标题旁（按用户 2026-09-08 调整要求）。
- 对话工作区使用统一边框和圆角，位于标题下方并以 flex 占满剩余高度；历史列表和消息各自滚动，输入区保持可达。
- 对话和智能体编辑区的可用高度引用 `--page-viewport-height`，不得硬编码扣减旧顶栏高度。
- 仪表盘保留统计卡片作为首屏内容，统一继承内容边距；登录与修改密码使用独立身份验证布局。

## 响应式

- 桌面侧栏 240px，900px 以下 200px，640px 以下为 72px 图标导航。
- 图标导航保留工作空间切换和账号入口；隐藏文字的导航提供可访问名称和悬停提示。
- 账号菜单不可超出视口，高度受动态视口限制并允许内部滚动。

## 适用页面与验收

覆盖首页、我的 Agent、对话、会议（含创建和详情）、工作空间、智能体（含编辑）、空间知识库、数据源、工作流、系统配置、用户与权限。

验收时检查：顶部页面标签栏可打开、切换和关闭页面；顶部间距一致；页面滚动时账号固定；菜单向上且可操作；聊天输入区和编辑区底部可达；无旧顶栏高度扣减；身份验证页面正常。

## 主题色保存

个性化设置页选择预设色或自定义颜色后立即应用并自动保存，不需要再次点击确认。主题色按用户账号存于当前浏览器，退出登录不清除，账号之间互不覆盖；登录页和应用页面在首次渲染前恢复所存颜色。保存失败须显示提示并提供重试，不能误报成功。

## 全局外观（浅色 / 深色）

- 个性化设置页在配色类型切换栏右侧提供“浅色、深色、跟随系统”三种外观，两组控件左侧起排并水平对齐；不额外显示外观标题或当前状态说明，窄屏时允许自然换行。
- 外观设置与主题色相互独立、选择后立即全局生效并保存到当前浏览器；默认使用“跟随系统”。跟随系统时须监听系统外观变化并实时切换，不要求刷新页面。
- 登录页和所有业务页面必须在首次渲染前恢复外观，避免浅色闪烁。组件不得自行读取系统主题或维护独立的深色状态。
- 页面和组件只使用语义变量：背景使用 `--bg`、`--surface`、`--surface2`，文字使用 `--text`、`--text2`、`--text3`，边框使用 `--border`；禁止新增固定的白色背景或仅适用于浅色模式的灰色文字。
- 表单、弹窗、菜单、卡片、表格、空状态、遮罩、提示状态和交互态均需在两种外观下保证清晰边界及可读对比度。新增页面验收必须同时覆盖浅色、深色及跟随系统三种选择。

## 页面标签页（2026-09-09）

- 左侧导航打开页面后，在内容区顶部新增标签；重复打开相同地址时激活已有标签。详情地址单独打开，浏览器前进、后退与标签选中状态保持同步。
- 标签切换保留页面表单、筛选、滚动和进行中的对话状态；每个页面使用独立路由上下文，后台标签的弹窗隐藏。关闭标签卸载对应页面，关闭当前标签激活右侧相邻标签（无右侧时激活左侧），至少保留一个标签。
- 标签栏横向滚动，激活标签自动进入可见区域；支持左右方向键、Home/End 切换和 Delete 关闭。
- 标签仅保留在当前应用会话；刷新后从当前地址重新打开。切换工作空间或登录用户时清理标签及页面状态。
- 页面可用高度统一扣减标签栏高度，账号入口仍固定在侧栏底部。浅色、深色与窄屏均遵循语义颜色和既有边距规范。

- 手动新建工作成功后关闭弹窗并刷新当前工作列表，不跳转详情；用户点击工作卡片时才打开独立详情标签，不同工作可以同时打开。

- 工作列表仅首次加载显示整页加载提示；切换分类、状态等筛选或刷新时保留筛选控件和当前结果，请求完成后更新数据，避免内容先清空造成闪动。
- 工作详情加载成功后以工作标题命名标签，修改标题后同步更新；长标题截断并通过悬停显示全文。

## 个人个性化（2026-09-10）

- 账号菜单提供“个性化设置”，所有登录用户均可访问 `/personalization`；系统配置仅保留供应商和模型管理。
- 配色顺序为纯色、撞色、渐变、玻璃、纹理。纯色合并原柔和、鲜明，含经典、科技、马卡龙、莫兰迪、糖果宝石、东方美学、欧式宫廷七类，每类 14 套，共 98 套；每类覆盖红、橙、黄、绿、青、蓝、紫、粉及中性色，并保留各自的饱和度和明度风格。原有颜色值保留，旧设置无需迁移。撞色、渐变、玻璃各 14 套；纹理含自然、金属、布艺、人文、历史、书艺、绘艺七类共 25 套，总计 165 套。每类另提供自定义入口，不计入 14 套预设。
- 玻璃提供全透（0px 模糊、清晰亮边）与磨砂（24px 模糊、乳白遮罩与细颗粒）。常驻边缘泛光提供 0–100% 滑块，默认 20%，按账号保存；右下角为主要光源，扩大渐消覆盖范围，左上角为较小的辅助光源，其峰值透明度严格为右下角的 30%。0% 同时关闭两角的主题色光晕，保留中性玻璃边缘。
- 鼠标高光与常驻光晕独立：仅距控件边界 140px 内响应，按距离平方衰减，每个控件单独计算朝向鼠标的位置。两按钮之间的光源应分别照亮左按钮右侧和右按钮左侧。禁止将鼠标位置写到全局主题变量造成所有按钮同步发光。离开窗口、切换主题/外观时清理临时高光；触摸输入不模拟悬浮光源。
- 纹理支持自定义主色与纹样，低对比纹样用于主要按钮，悬停略增强；色卡展示较清晰的纹理。原三拼色自动保留主色并恢复为默认木纹。
- 主题和外观在当前浏览器按账号隔离保存；首次迁移时将原浏览器偏好归入首个登录账号，其他账号使用默认值。
- 工作页面及创建弹窗的主要按钮使用共享 `btn btn-primary` 样式，渐变主题显示渐变，纹理主题显示主色与轻纹理。

### 材质与颜色分工

- 纯色主按钮使用经过对比度调整的主色；撞色用主色表达操作、搭配色表达导航/标签；渐变用于主要操作面。浅色配色的色卡保留原色，按钮可适度加深以保证文字可读。
- 纹理、玻璃主要用于操作与选中表面；输入框、表格正文和普通卡片保持中性底色，通过主题焦点、悬停与选中态完成适配。原生复选框/单选框不强制模拟材质，以保留平台交互能力。
- 深色外观的主题文字与导航图标使用提亮色，按钮实体背景仍使用独立按钮变量，不能用文字颜色替代按钮背景。
- 所有按钮必须保留 hover、focus-visible、disabled 状态；表单必须支持只读与 `aria-invalid`。颜色不能作为唯一状态信息，保留图标、标签或文本。
- 减少动态效果偏好下关闭控件过渡动画。主题更新不能触发表单重建、改变数据或执行任何操作。

### 验证入口

- `tests/theme-controls.browser.cjs`：六种材质状态（纯色、撞色、渐变、纹理、全透、磨砂）× 浅色/深色，共 12 组，验证主要按钮别名、表单底色/焦点、滑块、勾选、导航、标签与玻璃两角强度。
- `tests/personalization.browser.cjs`：七个纯色分类、玻璃强度实时保存/刷新恢复、鼠标双按钮方向、远处不受光、账号隔离及窄屏。
- `tests/work-candidate-theme.browser.cjs`、`tests/work-detail.browser.cjs`、`tests/page-tabs.browser.cjs`：实际工作按钮、详情操作、页面切换/状态保留回归。
- 原生系统下拉弹出窗口由平台绘制，本次自动化不声称覆盖各操作系统弹出层的视觉一致性。状态语义色、真实头像及文档原图不随主题改色。

### 记忆管理交互（2026-09-20）

- 用户界面统一使用“记忆”：补充记忆、有效记忆、记忆内容、记忆变化；Work 沉淀提示和记忆相关接口的错误提示保持同一用语。
- 记忆详情、补充记忆、纠正/事实变化和召回规则使用弹窗，复用共享 modal、表单与按钮主题样式。标题与关闭按钮固定顶部，内容独立滚动，底部放取消/保存等操作；窄屏保持视口内可操作。
- 弹窗支持 Escape、遮罩关闭、键盘焦点约束；关闭后在原触发元素仍存在且页面激活时恢复焦点。提交期间禁止重复操作和关闭。切换页面标签后隐藏后台弹窗并关闭下拉选项，保留未提交表单。
- 分类、状态、业务类型和可信度筛选使用 SearchSelect，选项支持搜索、键盘选择和主题明暗适配。下拉展开时 Escape 优先关闭选项，不同时关闭所属弹窗。
- 召回规则以独立草稿编辑，取消或关闭不保存；失败在弹窗内显示并保留输入。每个输入框右侧提供问号帮助图标，鼠标悬浮、键盘聚焦或触摸点击均可查看参数含义、范围和影响。
- 弹窗容器复用 MemoryDialog，字段帮助复用 MemoryFieldHelp，下拉选择复用 SearchSelect；不得在记忆列表中再展开详情、补充表单或召回规则面板。异常事项处理目前仍为页内表单。
- 弹窗桌面宽度上限 720px，外边距 20px；640px 以下外边距 12px、内部边距 16px。标题和底部操作保持可达，中部内容按剩余高度滚动。颜色和边框使用主题语义变量。
- 召回规则当前展示最多注入条数、上下文预算、候选上限、最低相关性和模型辅助治理开关。帮助提示必须说明预算为估算值、候选数与最终注入数的区别、相关性门槛及模型治理发生阶段，不暗示精确 Token 计量或 Focus 后台监控。
- 分类和状态选择即时生效；正文搜索通过搜索按钮或 Enter 提交，高级筛选通过应用按钮生效。默认状态排除已归档和已拒绝，不能标成“仅有效”。
- 验收覆盖浅色、深色、跟随系统窄屏；检查弹窗不越界、选择器优先处理 Escape、提示可通过键盘阅读、取消不保存、错误保留输入、切换弹窗后滚动恢复、后台页面没有残留浮层。模拟 API 的 UI 验证与真实数据端到端验证须分别记录。
- 完整业务交互、参数默认值/范围及本次发布记录参见 [产品设计第 10 节](PRODUCT_DESIGN_20260919.md#10-ui-设计与操作)。

### 玻璃材质与预设头像（2026-09-23）

- 玻璃浮层（下拉、菜单、弹窗、@提及）两种质地：**液态**为 72%/88% 半透明底 + `blur(28px)` 高饱和背景模糊，**磨砂**为 94%/96% 半透明底 + `blur(38px)` 大模糊；变量由 `utils/theme.js` 输出（`--glass-menu-background`、`--glass-menu-backdrop`）。
- 浮层穿透（下层文字透过菜单可辨）必须用「增强背景模糊 + 适度底色透明度」解决，禁止以提高不透明度或改纯实底的方式处理——那会消灭玻璃质感。历史教训：`backdrop-filter: url(#svg-filter)` 折射方案在 Chromium 真实页面会静默失败（能力检测通过、渲染输出为空），已回退，重启前须验证浏览器渲染成熟度。
- 智能体预设头像 17 个全部为多元化人物 SVG，经 `components/AgentAvatar.vue` 内联渲染跟随应用深浅主题（`html[data-theme]` 驱动 `.av-bg`，颜色由每个 SVG 根元素的 `--_av-bg-light/dark` 变量提供）；SVG 文件内嵌 `prefers-color-scheme` 供独立引用兜底；非预设路径自动回退 `<img>`。新增预设角色时同步更新 `Agents.vue` 的 `presetAvatars` 列表。
- 卡片、面板、弹窗、徽章等历史页面已全面改用主题语义变量（`--surface/--surface2/--text/--border/--success/--danger`），禁止新增固定白色背景或仅浅色可读的灰色文字；回归入口 `frontend/tests/card-theme-audit.browser.cjs`（浅/深双主题断言）。
- 玻璃鼠标边缘泛光：响应范围 130px（磨砂 95px），缓动时间常数 150ms，实现位于 `utils/glassLighting.js`；调整强度/范围时同步运行 `glass-lighting.browser.cjs`。

### 知识库控件补充（2026-09-16）

- 知识库本期暂定版详见 [知识库设计与编码规范](KNOWLEDGE_BASELINE_20260916.md)。目录区显示“总文件夹数”，总数包含所有子目录、不含虚拟根目录；各目录右侧数字表示直属文件数。数字列统一 24px、水平垂直居中并整列对齐，窄屏不得挤偏。
- 上传组件使用 compact 模式：空闲无额外占位，任务及结果在工具栏下方显示。不得隐藏整个组件导致进度消失；字节传输完成、接口保存成功及后台解析/摘要/索引完成分别表达。发布回归同时检查上传进度、文件夹标题与数字对齐。
- 知识库工具栏使用共享按钮类：新建文件夹、创建文本文档使用 `btn btn-ghost btn-sm`，上传文件使用 `btn btn-primary btn-sm`；弹窗保存、摘要编辑与保存、有效期保存同样使用共享主要按钮。组件局部样式只负责尺寸和布局，不覆盖主题材质。
- 新建文件夹与移动资源的目录选择复用 `SearchSelect`，展开列表随主题和明暗外观变化，支持搜索完整文件夹路径；保留根目录选项与禁止移动到自身及子目录的约束。
- 资源弹窗使用语义边框与主题焦点，名称与目录控件间距统一；弹窗及展开选项不得超出窄屏视口。移动文件时名称只读。
- `frontend/tests/knowledge-controls.browser.cjs` 覆盖六种材质 × 浅色/深色，以及窄屏跟随系统和中等宽度；验证按钮主题一致性、目录搜索、新建/移动提交、排除子目录和弹窗边界。设置 `LIVE_ORIGIN` 可使用已部署资源与隔离 API 数据复验。
