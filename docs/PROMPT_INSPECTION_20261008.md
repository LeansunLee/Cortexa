# 执行过程 Prompt 查看（2026-10-08）

- 主 Agent 模型调用、LLM 协作者模型调用、协作任务交接增加 `Prompt` 标签。
- 模型请求展示本次 messages、工具定义、运行时输出额度；Proxy 交接展示实际构造的请求正文和来源投影，不包含传输鉴权配置。
- 普通 LLM 对话的主模型调用同样记录 Prompt 引用。
- 点击标签按需读取；浮层分角色展示正文，工具定义和调用参数可折叠。
  支持滚动、错误重试、Esc 关闭和焦点返回，窄屏不越界。
- 请求正文保存在 `data/prompt_requests` 私有文件（0600），消息步骤只存引用；无需表结构变更。
- 接口 `GET /api/conversations/{conv_id}/prompts/{prompt_id}` 检查对话归属、当前 Agent 使用权限及对话调试权限。
  仅开启对话调试的用户显示标签。接口响应禁止缓存。
- 不保存模型内部 reasoning/thinking 元数据，不采集供应商鉴权头或连接配置。
- 仅新采集的请求显示标签；历史步骤未保存完整请求时不反推或编造提示词。
