# 聊天自动选择执行路径与个人调试权限

日期：2026-09-24。

## 用户界面

- 移除聊天页的「执行方式」选择，以及「目标状态 / 刷新状态 / 新目标」操作栏。
- 输入区统一使用普通消息提示；附件入口保持可用。需要用户决定的协作授权仍显示。
- 服务器根据显式参与者、任务表达和智能体类型选择执行路径；当前为确定性规则，不增加单独的分类模型调用。普通问候走原对话路径，明确任务和协作请求使用已启用的 Goal Runtime；Proxy 主智能体和附件仍走兼容路径。
- 已完成或停止的任务不阻止发送下一条任务；等待补充的任务可直接回复继续。明确另起话题后不恢复旧任务，重新打开会话只依据最后一条消息恢复关联。

## 调试权限

- 新增工作空间权限资源 `conversation.debug`，显示名称「查看个人对话调试信息」。管理员可通过现有角色管理授权；不自动扩大现有角色权限。
- 从系统配置移除用户操作开关，放到账号菜单的「个性化设置」。未获资源授权的用户看不到此设置。
- 开关默认关闭，按用户保存到服务端私有 `data/user_preferences/{user_id}.json` 文件，目录权限 0700、文件 0600，采用原子替换。
- 实时调试事件、最终回复中的调试轨迹以及历史消息中的调试轨迹，均要求资源权限与个人开关同时有效。关闭功能或失去资源权限后不返回调试轨迹。
- 既有全局 `conversation_debug_enabled` 保留为后台采集总开关，发布时开启；它不能绕过个人权限和开关。
