# UI 审查与主题适配记录（2026-09-28）

## Changed / Theme System

完善现有主题体系，没有新增 UI 框架。应用根节点增加表面、文字、边框、阴影、间距和控件高度语义令牌；公共组件消费 `surface-card`、`surface-panel`、`surface-dialog` 等表面。提高浅色和深色弱提示文字的对比度，清理工作空间选择器的重复边框与底色。

会议、工作、数据源、协作卡片、提及菜单、危险确认、工作编辑器及 Toast 的多组固定状态颜色、遮罩和阴影改用语义令牌。首页和工作流的遮罩统一为 `modal-overlay`，避免与弹窗内容的 `modal` 材质规则混用。

## Components / Glass Rules

公共按钮、输入、SearchSelect、复选框、滑块、选中导航、标签、表格、Card、Panel、Dialog 和菜单继续使用同一结构。普通 Card 保持实体表面；重要 Panel 使用克制的玻璃面；Dialog/Popover 使用菜单级模糊；密集内容不叠加玻璃。动态玻璃光源的选择范围同步收窄到控件、重要面板与浮层。

SearchSelect 的尺寸、圆角与阴影改用公共令牌，纹理主题下的选项列表保持清晰内容面。非玻璃主题无通用遮罩模糊。

## Pages / Design System

根据 Router 遍历首页、工作列表与详情、对话、会议、我的 Agent、工作空间、智能体、知识库、数据源、系统配置、个性化、权限、模型用量、工作流、Agent 操作页及身份验证入口。新扫描使用隔离 API 数据，重点覆盖路由加载、空状态、主题切换、普通 Card 与选择器材质、脚本错误和全页横向溢出；已有浏览器用例补充新建/编辑、知识库浮层、表单、长内容、分页、权限及窄屏交互。

`UI_LAYOUT_GUIDELINES.md` 增加设计原则、架构、语义令牌、字体/间距/圆角、表面与卡片、控件状态、动画、响应式及 Theme × Component Matrix。规范中的玻璃规则与公共实现对应。
