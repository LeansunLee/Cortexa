# 知识库设计与编码规范（暂定版）

定版日期：2026-09-16。适用 AgentDevStu 的空间知识库、Agent 独立知识库及共享知识库引用界面。

本文件记录本期已确认的产品和设计约束，作为后续开发、评审、回归与发布依据；不新增软件版本号。全局布局与主题以 [UI 布局规范](UI_LAYOUT_GUIDELINES.md) 为准，整体架构参见 [项目开发基线](PROJECT_BASELINE_20260916.md)。用户后续明确提出的变更可以更新本规范。

本文依据当前仓库实现及本次会话已完成的上传进度、目录数量修复整理。设计定版不等于所有历史代码已全面审计，也不等于所有本地改动已与服务器逐项同步；发布记录必须单独说明构建来源与验证范围。

## 1. 产品边界与资源模型

知识库负责文档的归集、组织、阅读、维护和检索，为 Agent 提供可追溯的知识来源。

| 对象 | 定版约定 |
| --- | --- |
| 空间知识库 | 隶属当前工作空间，可供 Agent 绑定引用；不同工作空间的数据隔离 |
| Agent 独立知识库 | 隶属指定 Agent；文档可推送至同一工作空间的公共知识库 |
| 共享引用界面 | 使用同一知识库卡片的只读模式，支持查看、预览、下载；修改入口按权限和上下文控制 |
| 文件夹 | 属于一个知识库，支持多级父子关系；根目录以空目录 ID 表示 |
| 文档 | 属于一个知识库和一个目录，记录创建者、有效期、摘要及处理状态 |
| 原件、正文与索引 | 分别承担下载/预览、阅读/检索、召回职责，不能相互替代 |

本期范围包含：知识库创建、重命名、启停、删除；目录创建、重命名、移动、删除；上传、创建和编辑文本文档；名称搜索、类型筛选、预览、下载、摘要、有效期、批量操作、文档推送以及处理失败后的重试。

以下不因本次定版而成为默认承诺：断点续传、文件版本历史、多人实时编辑、递归删除非空目录、跨工作空间分享、所有格式无损在线编辑、独立可靠任务队列。新增这些能力须单独明确需求与验收条件。

## 2. 页面与交互规范

### 2.1 页面框架与卡片

- 使用全站侧栏、顶部页面标签和统一内容边距；不增加全局账号顶栏，不重复页面主标题，不在页面根节点叠加整页 padding。
- 页面左对齐、知识库列表占内容区全宽；知识库数量和共享范围使用紧凑信息行。
- 知识库卡片头展示名称、当前路径、文档数量/容量、启停状态、展开/收起与更多操作。
- 知识库展开与目录树展开是独立状态；目录区可折叠，为文件列表保留空间。
- 新建文件夹和创建文本使用共享次要按钮；上传文件使用共享主要按钮。操作布局不得覆盖全局主题材质。

### 2.2 文件夹与数字对齐——必须保留

- 目录区标题固定为 **“总文件夹数”**，不得退回“资源管理器”作为可见标题；展开/收起按钮的可访问名称仍可描述“资源管理器”。
- 标题数字取该知识库全部文件夹的数量，包含子文件夹，不计虚拟根目录，不受当前展开层级影响。
- 根目录及各文件夹右侧数字是该目录直接包含的文件数，不是子文件夹数，也不是递归累计文件数。
- 总数和各目录数字使用统一的 24px 固定宽度列，水平、垂直居中；采用等宽数字，整列中心对齐。
- 总数适当加重；文件数使用辅助文字色。窄屏下调整标题、按钮及间距，不能挤偏数字列。
- 目录树展开箭头仅控制子目录展开；目录选择与文件列表中的进入目录操作按现有行为保持一致。长名称省略，并保留完整路径提示。

### 2.3 搜索、筛选与选择

- 文件名搜索和类型筛选覆盖整个知识库，不局限于当前目录；界面明确提示“整个知识库”的结果范围。
- 普通浏览显示当前目录；筛选时展示全库匹配文件，提供返回文件夹浏览和定位文件的路径信息。
- 文件列表当前每页 10 个；此处是前端展示分页，不应误写成服务端分页。
- 多选以资源 ID 保存，支持跨页；本页全选仅作用于当前可见且允许选择的资源。
- 批量工具栏展示总选择数以及不在当前页的选择数；提供取消选择，支持 Esc。
- 名称搜索属于管理界面筛选；语义/全文检索属于后端检索能力，两者不能混淆。

### 2.4 上传——必须保留

- 工具栏按钮打开文件选择器；支持多文件，当前队列逐个上传，单文件上限 500 MB，拒绝空文件。前后端均校验。
- 使用 KnowledgeUpload 的 compact 模式：空队列不占布局；有任务时在工具栏下方显示进度区。
- 禁止用父级 display:none 永久隐藏整个上传组件。文件输入可隐藏，但进度区必须可见。
- 逐文件状态为 waiting → uploading → processing → success / failed；失败可重试，完成结果可收起，忙碌时禁用重复发起。
- 展示整体进度、单文件进度、成功/失败/总数和错误信息；整体进度按文件字节数加权。失败项计入队列结束进度，因此 100% 不能单独解释为全部成功。
- 字节发送完毕到接口响应前显示“服务器处理中…”。接口成功表示上传已接收保存，不表示 OCR、摘要及索引已全部就绪。
- 文档后台处理另由文档状态显示与轮询更新，不得制造虚假的解析百分比。
- 卸载组件时中止前端请求；请求中止或超时不保证服务端未保存，提示用户刷新确认，不能误报已回滚。

### 2.5 文档操作与弹窗

- 预览、下载原件、编辑正文、编辑摘要是不同操作；二进制内容/base64 不得直接当作摘要展示。
- 仅纯文本类文档支持正文编辑；保留 Markdown 空白与换行。PDF、Office、图片走对应预览和提取路径。
- 创建/移动目录选择复用 SearchSelect，可搜索完整路径、选择根目录；移动文件时文件名只读。
- 移动文件夹不得选择自身及任意子孙目录；前端限制与后端检查同时保留。
- 删除前说明对象和影响；文件夹仅允许删除空目录，批量删除中存在非空目录时整批拒绝。
- 有效期支持永久有效或指定日期。过期文件仍可管理、预览和下载，但不进入有效知识检索。
- 弹窗支持明确标题、关闭/取消、忙碌状态、错误提示、键盘焦点和 Escape；不得超出视口。
- 页面标签切换保留已有状态；后台标签弹窗不得遮挡当前页，关闭标签则清理对应组件资源。

### 2.6 主题与响应式

背景、正文、辅助文字和边框使用全局语义变量；主要按钮与进度填充继承主题色/材质。禁止新增固定白色背景、只适用于浅色的灰字或局部紫色主要按钮。成功、失败、警告同时保留文字语义。

保持纯色、撞色、渐变、纹理、全透玻璃和磨砂玻璃在浅色/深色下可读；窄屏不得造成整页横向溢出。局部宽文件列表可在自身容器内滚动。

## 4. 前端编码约定

1. script 中的 ref 通过 .value 访问；派生列表、路径、统计和权限使用 computed，避免多份可变副本。
2. 列表 key、选中状态和提交参数使用稳定 ID；显示名称不能当资源身份。根目录使用 null，不能擅自改成字符串哨兵值。
3. 权限输入保持 canManage、canUse、readonly 的含义；隐藏按钮只改善体验，不能作为后端授权依据。
4. 刷新使用请求序号阻止旧响应覆盖新结果；保留已有数据，成功后清理失效选择项和已不存在的当前目录。
5. 有 pending/processing 文档时当前实现每 5 秒轮询；无任务停止继续调度。卸载清理定时器、事件监听与请求。
6. 上传通过 Axios onUploadProgress 和 AbortController；保留当前上传超时及针对超时的明确反馈。
7. 异步动作使用忙碌状态与 try/catch/finally；失败不得冒充成功或静默丢弃用户输入。
8. 共享按钮样式负责颜色、材质和状态；局部 CSS 负责布局、尺寸与间距。精简模式用明确 prop 表达，不依赖隐藏整个组件的样式技巧。
9. progressbar 保留可访问名称、范围和当前值；纯图标按钮提供名称，状态不能只靠颜色表达。
10. 上传完成、文档保存等通过事件驱动父级刷新；避免无关组件共享可变状态导致串库、串文档。

## 5. 后端、存储与权限约定

### 5.1 归属和授权

- 所有知识库路由经过工作空间范围检查；涉及文档或目录时继续验证其属于路径中的知识库。
- knowledge.manage 控制管理能力；knowledge.use 控制使用/上传能力。文档修改依据管理权限或“有使用权限且为创建者”判断。
- 前端只读模式不替代服务端校验；批量资源必须逐项验证存在性、所属范围和操作权限。
- 名称、目录层级、重复提交及批量数量在后端校验；同目录文档名称按当前大小写不敏感规则检查冲突。
- 文件夹移动防止循环；父子目录同时选中移动时按顶层选中目录处理。

### 5.2 数据与文件

主要表为 t_knowledge_bases、t_knowledge_folders、t_documents、t_document_chunks。**不得私自修改数据库表结构；需要变更时先向用户说明。**

- 原件和完整正文存文件系统；数据库存资源信息、检索摘要、处理状态及索引数据，不把大段原始二进制或全文塞进列表记录。
- 正文通过临时文件、刷新落盘和原子替换写入；原件是预览和下载的重要来源，不能用提取文本重建代替。
- 文本长度不超过 1000 字符时可直接作为摘要；长文本由后台生成摘要，失败保留截断回退。make_summary 当前默认截断 2000 字符，这与“1000 字符短文直存阈值”含义不同。
- 摘要、正文和索引分别维护；正文修改后触发必要的摘要/索引更新，手动摘要及修订状态不能被陈旧后台结果覆盖。
- 文件系统与数据库并非天然同一事务：保留上传失败清理、正文提交失败恢复和删除提交后清理等补偿措施。
- 批量操作先完整校验再变更；不能部分删除后才发现其余对象无权操作。

### 5.3 异步处理与检索

- 上传先可靠保存，再触发提取、摘要和索引；分别维护 extraction_status、summary_status、index_status 及对应错误信息。
- 后台任务及 SSE/Streaming 使用独立数据库会话，不能复用已经结束的请求会话。阻塞文件/转换操作不得阻塞异步事件循环。
- 同文档任务使用现有任务锁和修订校验，保留失败重试与恢复机制；不把进程内后台任务描述成持久化任务队列。
- Agent 检索限制在允许使用的知识库内；停用库、非有效文档及过期内容不进入有效知识上下文。日期边界遵循当前上海时区规则。
- API 检索支持 bm25、hyde、multi_query、ensemble、parent_child 等配置；实际可用性仍取决于模型、索引与运行环境。不得把 API 能力等同于所有 Agent 都使用同一检索路径。
- 引用结果保留文档身份与来源。处理失败、正文不可读或无命中时给出真实状态，不能编造知识依据。
- Agent 独立库推送到同工作空间公共库属于复制：保留源文档，复制原件/正文并重建目标索引；重复推送同一来源到同一目标返回已有结果。

## 6. API 扩展约定

入口统一为 /api/knowledge。具体请求结构以 knowledgeApi、api/knowledge.py 和 schemas.py 为准。

| 接口域 | 当前主要路径 |
| --- | --- |
| 知识库 | 根列表/创建，/{kb_id}，/{kb_id}/name，/{kb_id}/status |
| 文件夹 | /{kb_id}/folders，/{kb_id}/folders/{folder_id}，其 /move 子路径 |
| 入库与正文 | /{kb_id}/upload，/{kb_id}/documents，文档 /content |
| 元数据与处理 | 文档 /name、/validity、/summary、/regenerate-summary、/extract、/reindex |
| 预览与下载 | 文档 /preview、/pages/{page}、/raw，/documents/batch-download |
| 批量资源 | /documents/move、/resources/move、/documents/batch-delete、/resources/batch-delete |
| 共享与检索 | 文档 /push，知识库 /search、/reindex |

新增接口复用范围校验、权限检查和业务辅助函数。错误区分无权限、不存在、冲突、格式/大小校验与服务器失败；前端展示可理解的信息，不能把服务器堆栈或凭据返回用户。

## 7. 验证与发布规范

### 7.1 必须保护的回归点

- 空间库和 Agent 库使用同一组件；共享只读场景不泄露修改入口。
- 总文件夹数统计正确，根目录/文件夹文件数语义不变，数字居中且整列对齐。
- 上传空闲隐藏、任务时可见、进度更新、服务器处理提示、失败重试和结果收起正常。
- 目录切换、全库搜索、类型筛选、跨页选择、批量操作及文件定位保持一致。
- 预览/下载保留原件，文本编辑后读取新正文，摘要失败保留已有内容。
- 不能跨工作空间操作，不能移动目录到其子目录，不能误删非空目录或他人文档。
- 浅色、深色、主题材质和窄屏检查通过，浏览器无运行错误；弹窗与页面标签生命周期正常。

### 7.3 发布与防回退

1. 对照本定版文档确认交付范围，检查本地源代码、线上源代码与线上构建资源的差异。线上旧文件不能直接当作完整产品基线。
2. 有未提交或其他任务改动时，保留原工作区；需要隔离构建可以使用临时副本，但必须主动合入本次范围内此前已确认的设计，不能只验证最新一项修复。
3. 构建前端并运行相关回归。视觉问题必须用浏览器确认实际可见性和位置，不能仅凭源码包含某段文字判定通过。
4. 备份可回退资源；源代码与构建产物按同一发布范围同步。记录日期、构建来源、包含的修复、保留的既有行为和验证结果。
5. 按项目约定验证后直接部署开发服务器，通过 rsync 同步并重启 agentdevstu.service；检查服务状态、页面 HTTP、资源一致性及相关线上页面。
6. 报告区分本地测试、线上资源配合模拟 API 验证和真实业务验收。文档修改本身无需重启服务。
